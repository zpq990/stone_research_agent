# 知野 ZHIYE — AI 调研单页原型

一个面向陌生领域调研的单页网站原型。目标是：**用 60 分钟，从完全陌生到形成自己的判断，并交付一份完整的调研文档。**

## 本地查看

最简单的方式是直接双击 `index.html`。

也可以在项目根目录启动一个本地静态服务器：

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

然后访问 `http://127.0.0.1:4173`。

## 页面包含

- 品牌首页与 60 分钟调研方法说明
- 可交互的研究主题输入、快捷主题与表单校验
- 「开始调研」弹窗：研究流程演示 → 调研文档结构预览
- 报告章节标签切换、FAQ 手风琴、移动端菜单
- 可导出 / 打印的文档视图
- 完整的桌面端与移动端响应式布局
- 自托管的中文衬线 / 无衬线字体子集，离线可用

## 重要说明

当前版本是**纯前端产品原型**，没有接入真实 AI / 检索接口：

- 首页示例报告和研究流程弹窗是演示内容，用于展示产品形态与文档结构；
- 弹窗生成的是一份结构预览，不是真实研究结论；
- 页面内已明确标注「交互原型 · 演示模式」。

## 下一步接入建议

1. 将主题提交到后端研究任务接口，返回可订阅的任务 ID。
2. 用 SSE / WebSocket 替换前端的模拟进度，实时推送问题拆解、信源收集、交叉验证、成稿四个阶段。
3. 报告内容改为后端结构化 JSON 渲染，并为每条结论保留 `source_url`、引用位置、发布时间与置信度。
4. 把当前的「导出 / 打印」升级为服务端生成 PDF / Markdown，同时支持分享链接与版本历史。
5. 增加登录、研究历史、团队空间与私有资料库。
