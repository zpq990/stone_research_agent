# 石头 — 给我一个陌生主题，还你一份有出处的报告

「石头」是一个纯静态的 AI 调研产品单页原型。它专门对付「好像懂一点、其实说不清」的问题：先拆问题、定范围，再去翻财报、论文和监管文件，最后交付一份出处、分歧、没查清的地方都写明的调研文档。核心承诺是**可信**，不是快。

页面采用简约木质风：纸色与石色的底、胡桃木的深色方法区、本地石墙与林地照片。中文文案使用自托管字体子集，可离线打开。

## 本地查看

最简单的方式是直接双击 `index.html`。

也可以在项目根目录启动一个本地静态服务器：

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

然后访问 `http://127.0.0.1:4173`。

## 页面包含

页面是折叠式的，三块主要内容默认全部收起；访客先看到 Hero、与通用 agent 的对照，再决定展开哪一段：

1. **Hero**：H1「给我一个陌生主题，还你一份有出处的报告。」+ 一句口语化说明 + 一个主题输入框 + 4 个快捷主题。右侧是一张「样本报告」摘录卡：核心判断、来源、把握、分歧，以及展开完整报告的入口。
2. **对照区**：一张常显的五行对照表，比较通用 agent 与石头在开始、过程、证据、冲突、不确定时的不同做法。
3. **示例报告**（`#report`）：完整展开一份「固态电池，离量产还有多远？」的样本报告，包含执行摘要、核心判断及出处、一处 A/B 分歧、把握程度和信源列表。
4. **怎么做**（`#method`）：胡桃木深色区块，用三个动作说明方法——拆问题、找证据、标分歧并写成文档。
5. **常见问题**（`#faq`）：3 条原生折叠问答，同时只展开一条。
6. **材料照片带**：四张本地照片（海边石墙、雾中林地、多尔多涅老石墙、碎石小路）与一句收束文案。
7. **页脚**：品牌语、导航、版权、照片署名。
8. **调研弹窗**：提交主题后演示「拆解问题 → 检索与阅读 → 交叉验证 → 组织文档」的进度，随后展示可打印的文档结构预览。

## 交互说明

- **折叠一次只开一段**：点击标题、页头/页脚导航，或带 `#report` / `#method` / `#faq` 的链接，都会展开对应段落并收起其他段落。
- **地址栏 hash 可直达**：打开 `index.html#faq` 会自动展开常见问题。
- **单表单**：页面只有 Hero 一个调研表单；快捷主题只填入输入框，不自动提交；空提交会就地显示错误，不打开弹窗。
- **弹窗演示**：约 1.6 秒走完四个阶段，可「跳过演示，直接看文档」；「再研究一个」关闭弹窗并清空输入。
- **导出 / 打印**：只打印生成的文档，隐藏页面与工具栏。
- **无障碍与动效**：导航、折叠、FAQ 均为原生控件；开启 `prefers-reduced-motion` 时内容直接显示，不依赖动画。


## 重要说明

当前版本是**纯前端产品原型**，没有接入真实 AI / 检索接口：

- 示例报告、进度阶段、文档结论、信源和机构判断都是演示内容，用于展示产品形态与文档结构，不是真实研究结果；
- 弹窗生成的是一份文档结构预览，不是真实调研结论；
- 页面内已明确标注「交互原型 · 演示模式」，示例区也注明「示例报告为结构示例，不是真实研究结论」。

## 下一步接入建议

1. 将主题提交到后端研究任务接口，返回可订阅的任务 ID。
2. 用 SSE / WebSocket 替换前端的模拟进度，实时推送问题拆解、信源收集、交叉验证、成稿四个阶段。
3. 报告内容改为后端结构化 JSON 渲染，并为每条结论保留 `source_url`、引用位置、发布时间与把握程度。
4. 把当前的「导出 / 打印」升级为服务端生成 PDF / Markdown，同时支持分享链接与版本历史。
5. 增加登录、研究历史、团队空间与私有资料库。
