# 首页改版建议：去时间化与内容精简

> 记录日期：2026-11-03
> 状态：已落地（2026-11-03），后续已演进。品牌由「知野」改为「石头」，按本文件的 5 块结构重写页面；之后又把「示例报告 / 怎么做 / 常见问题」改成默认收起的折叠区，并移除了第二个 CTA 表单。当前结构以 `index.html` 与 `docs/CLAUDE.md` 为准；最终文案口径与术语规范以 `document/项目方向定稿.md` 为准。文中历史文案（包括旧 H1「陌生主题，查成能复查的报告。」与「置信度」）仅作过程记录，不再使用。
> 范围：`index.html`、`assets/styles.css`、`assets/app.js`

## 一、总体结论

去掉“一小时 / 60 分钟”叙事是对的，但需要同时完成两件事：

1. **核心承诺从「快」换成「可信」**。主打时间会让用户拿产品和 ChatGPT / Perplexity 比速度，这是劣势；而“每个结论能查出处、能看到分歧”是搜索摘要给不了的价值，也更符合原型实际做到的事。
2. **时间承诺要用可验证的数量补位**。原先是“60 分钟”承担“具体”的角色，建议替换为页面上已有的数字：14 个一手信源、3 处标出的分歧、每条结论带出处 / 发布时间 / 置信度。

## 二、标题方案

### 推荐主标题

> **从完全陌生，到有自己的判断。**

这是当前 H1 的后半句，删掉“用一小时”后更完整有力：同时给出起点（陌生）与终点（判断），不承诺速度，也不像广告语。

配套 `<title>` / og:title：

> **知野 ZHIYE — 陌生领域，也要有自己的判断**

### 备选（按语气分组）

**判断向（最稳，推荐）**

- 不懂的领域，也能有自己的判断。
- 面对陌生领域，你要的不是答案，是判断。
- 别急着下结论，先把它搞清楚。

**证据向（最能建立信任）**

- 每一个结论，都有出处。
- 调研不是搜资料，是留下能复查的判断。
- 不是一份资料合集，是一份可以拿去用的判断。

**品牌向（更有记忆点，风险稍高）**

- 把陌生领域，读成一张地图。
- 在未知里，长出判断。（适合做品牌 Slogan，不适合单独当 H1）
- 给我一个陌生的词，还你一份能用的调研。

**排序建议**：`从完全陌生，到有自己的判断` 最适合 H1；`每一个结论，都有出处` 最适合副标题或表单下方小字。

### 推荐组合

- H1：从完全陌生，到有自己的判断。
- Title：知野 ZHIYE — 陌生领域，也要有自己的判断
- Lede：给我一个你不熟悉的主题，知野交给你一份每个结论都能复查的调研文档。
- 表单下方特点：14 个一手信源 · 3 处标出的分歧 · 出处可查

## 四、内容精简方案

### 判断标准

这是原型，不是完整官网。访客应在 2 屏内完成两件事：**相信有价值**、**想立刻输入主题试一试**。当前 10 个区块中 6 个在“解释产品”、只有 1 个在“证明产品”，解释稀释了证明。

原则：**留一个足够深的例子，删掉所有泛泛的解释。**

### 建议保留的 5 块

1. **Hero**：新标题 + 一句 lede + 输入框 + 4 个主题快捷词。
2. **一份示例报告**（核心）：沿用“固态电池”一条线，展示 3–4 个核心判断、1 条带出处的结论、1 处明确标出的分歧、置信度。这是唯一需要“多”的地方，用来替代说服性文案。
3. **怎么做到**：3 步，一行一步（拆问题 → 找证据 → 标分歧 / 给判断），不要时间轴和长段落。
4. **CTA**：一个输入框或按钮，回到“开始调研”。
5. **FAQ**：最多 3 条。

### 删减与合并

| 区块 | 处理 |
|---|---|
| Marquee 滚动条 | 删除，纯装饰，占一屏高度 |
| Problem 三张卡（收藏≠理解等） | 删除，或压缩成一行三短语 |
| Method 四步时间轴 | 压成 3 条短句，保留「建图 / 搜证 / 校验 / 成稿」的命名 |
| Deliverable 六个标签页 | **只保留一页完整示例**，其余标签删除 |
| Topics 六张卡 | 删除；四个快捷主题已在输入框下方，功能重复 |
| Manifesto | 删除，或收成页脚一句话 |
| FAQ 6 条 | 保留 3 条：一次调研包含什么、可信吗、和搜索有什么区别 |

### “一个例子”的做法

目前同一份示例被复用了三次（Hero 缩略卡、Deliverable 标签页、弹窗文档），详略不一，反而抓不住重点。建议只做两次：

- **Hero**：只露一行最有冲击力的结论，例如「固态电池的量产瓶颈不在材料，在良率和成本。」
- **示例区**：完整展开这一份文档，要具体到像真的。最能建立信任的不是排版，而是这类句子：
  - 「A 机构预计 2027 年量产，B 机构预计 2030 年——两方对‘量产’的定义不同。」
  - 「该结论来自 2024 年 11 月的一手财报，非媒体转述。」
  - 「置信度：中。原因是仅有两家独立信源。」

比「14 SOURCES / 3 CONFLICTS」标签更能打动人。

## 五、附带影响

去掉时间叙事之后，弹窗里 2.8 秒的四阶段进度演示失去“模拟 60 分钟”的意义。建议二选一：

- 缩短到约 1 秒后直接出文档；
- 去掉进度动画，点击后直接展示示例文档。

用户来看的是结果，不是加载动画。此项需要单独出方案后再改。
